## Sobre mim

Sou formado em Ciência da Computação pela UFC (Campus Russas) e atuo como desenvolvedor na [Starke Vision](https://github.com/starkevisionwebservices), empresa de tecnologia focada em aplicações de IA, automação inteligente e sistemas sob medida.

Hoje trabalho com sistemas web para clientes, automações de WhatsApp com n8n, plataformas para o setor hospitalar e soluções de IA para o setor público. Também sou 2º Secretário do Inova Araripe, hub de inovação do Sertão do Araripe.
